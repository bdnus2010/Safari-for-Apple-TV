# Safari-for-Apple-TV
Safari for Apple TV
Features include:
- Compact keyboard with .com, email-domain shortcuts, and access to tvOS dictation.
- Google, YouTube, ChatGPT, and BrowserLeaks shortcuts.
- Add, edit, and remove custom home-page shortcuts.
- Audio and video playback.
- Ad and popup filtering, including best-effort YouTube ad filtering.
- Downloads disabled.
- Private browsing data cleared when leaving the app.
Requires tvOS 26 or later. Distributed as an unsigned IPA for signing and sideloading.
